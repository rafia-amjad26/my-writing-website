# Rafia | Writing Universe

A personal portfolio website where storytelling meets technology.

This project reflects my journey as a BSCS student and a writer, combining creative writing with web development to build a unique digital storytelling experience.

---

## About the Project

"Writing is not just words for me… it's emotion, identity, and truth."

This website showcases my original stories, including:

- Hinal — a story of pain, power, and truth  
- Makhtoom — the beginning of my writing journey  

Each story is presented with:
- Dedicated pages  
- Character sections  
- Scene-based storytelling  
- Urdu and English integration  

---

## Features

- Dark aesthetic UI with purple/pink theme  
- Story pages with organized content  
- Scene-based storytelling (Hinal first scene included)  
- Character pages with dialogues  
- Urdu typography integration  
- Interactive navigation between pages  
- Contact section with GitHub and LinkedIn links
